# Cappuccino Macchiato

Adds the dark [Catppuccin Macchiato](https://catppuccin.com/palette/) palette as a Paseo app theme.

## Installation

```sh
paseo plugin install /absolute/path/to/paseo-plugins/plugins/cappuccino-macchiato
```

Then pick **Cappuccino Macchiato** in **Settings → Appearance**.

## Development

```sh
paseo plugin reload cappuccino-macchiato
paseo plugin logs cappuccino-macchiato
```

The theme is defined in `index.ts` and has no plugin-specific settings.
